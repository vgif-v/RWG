## 📝 **Customization Quick Tips**

### Change Letter Text
File: `components/LoveLetter/LoveLetter.tsx`
```typescript
const DEFAULT_LETTER = `[Your custom message]`;
```

### Change Colors
File: `app/globals.css`
Search for `#FFB6D9`, `#FFE4EC`, etc. and replace

### Adjust Animation Speed
Each component has a `duration` property in animations
Lower = faster, Higher = slower

### Add Sound
Files: `public/sounds/`
Uncomment refs in `app/page.tsx`
